# Практические задания по циклам на Python (Часть 3)

Набор из пяти консольных программ на Python 3, охватывающих фильтрацию кратных чисел, суммирование нечётных значений, возведение в степень через цикл, подсчёт чисел по знаку и вывод прямоугольника вложенными циклами.

## Список заданий

1. **Задание 1. Числа, кратные трём** (`task1_multiples_of_three.py`)  
   Запрашивает целое положительное число `N` и выводит все числа от `1` до `N`, которые делятся на `3` без остатка.
2. **Задание 2. Сумма нечётных чисел** (`task2_odd_sum.py`)  
   Вычисляет и выводит сумму всех нечётных чисел от `1` до `100` (`2500`).
3. **Задание 3. Степень числа** (`task3_power.py`)  
   Запрашивает число `A` (целое или вещественное) и целую положительную степень `N`, затем вычисляет $A^N$ с помощью цикла без использования оператора `**`.
4. **Задание 4. Подсчёт положительных чисел** (`task4_sign_counts.py`)  
   Последовательно считывает 10 целых чисел и определяет количество положительных чисел, отрицательных чисел и нулей.
5. **Задание 5. Прямоугольник из символов** (`task5_rectangle.py`)  
   Запрашивает ширину и высоту и выводит прямоугольник из символов `*` с помощью вложенных циклов (например, для `5 × 3` выводит 3 строки по 5 звёздочек).

## Структура проекта

```text
python-loops-tasks-3/
├── cli_utils.py                 # Общие утилиты ввода-вывода и проверки чисел
├── main.py                      # Единое интерактивное меню для запуска всех заданий
├── task1_multiples_of_three.py  # Задание 1: числа от 1 до N, кратные трём
├── task2_odd_sum.py             # Задание 2: сумма нечётных чисел от 1 до 100
├── task3_power.py               # Задание 3: возведение числа в степень циклом
├── task4_sign_counts.py         # Задание 4: подсчёт положительных, отрицательных и нулей
├── task5_rectangle.py           # Задание 5: прямоугольник из символов *
└── tests/
    └── test_tasks.py            # Модульные тесты (unittest)
```

## Запуск

Требуется Python 3.10 или выше.

Запуск через единое меню:

```bash
python main.py
```

Запуск каждого задания по отдельности:

```bash
python task1_multiples_of_three.py
python task2_odd_sum.py
python task3_power.py
python task4_sign_counts.py
python task5_rectangle.py
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```
